## Priority Issues

- **[P1] Command palette: Escape doesn't close it, and it's undiscoverable.** Confirmed twice independently: B found no Escape handler (plain cmdk `Command`, not `Command.Dialog` — CommandPalette.tsx:131) while the input renders an "Esc" kbd badge; QA proved via DOM check + screenshot that Escape leaves it open (backdrop click the only close). Also no role="dialog"/aria-modal, and no visible trigger anywhere (mouse/touch users can never open it). Fix: Escape handler + dialog semantics + a "Search ⌘K" affordance in the sidebar.
- **[P1] One-click irreversible single approve/reject** (Approvals.tsx:556-576). Bulk got the two-step confirm; the single path — the most common action — executes real agent actions instantly, 8px from its destructive twin. Fix: same inline confirm for live sources only (SIMULATION_SOURCES check exists), or a 5s undo-window toast.
- **[P2] Three tab systems + dual agent-detail experiences.** Settings ink-underline vs Authority accent-underline vs AgentDetail gray-underline vs CodeTabs pills; and the drawer (5 stats, not URL-reflected) vs /agent/:id (11 stats) read as two products. Fix: one shared Tabs; reflect the drawer in the URL (?agent= pattern already exists on Spend).
- **[P2] AgentDetail header overload** — up to 12 equal stat columns above four stacked panels; plus a ⛓ emoji in an all-Lucide system. Fix: cap at Total/Irreversible + top 4 with "+N more".
- **[P2] Reduced-motion gaps**: framer-motion (AppShell/CommandPalette, 0 useReducedMotion), drawer translateX transitions, Login rAF drift loop, History count-up — none damped; only .ag-* CSS transitions are.
- **[P2] Mobile fleet clipping**: 375px stat-card row and search/sort toolbar clip at the right edge with no scroll affordance ("UNGU", "Highe").
- **[P2] Performance debt** unchanged: 14 static route imports, no virtualization (History/Approvals), zero memoization in the largest pages.
- **[P3] Cluster**: ~8 placeholder-as-label inputs; 10 remaining inline outline suppressions (Input.tsx, palette, Login handlers); Settings loading inconsistencies + window.confirm; 10× hardcoded en-US; sample "$4,280/mo" adjacent to real "$0" stat; tan/warning tone on a positive growth badge; duplicated CopyButton and action-risk classifier regexes.
